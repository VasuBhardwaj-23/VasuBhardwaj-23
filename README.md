### 💫 About Me

* 🔭 **Currently Building:** End-to-end Data Analytics projects and practical BI reports using **SQL, Power BI, Python, Excel, and DAX**.
* 📊 **Core Focus:** Turning multi-table messy datasets into reliable Star Schemas, crisp business metrics, and easy-to-read dashboards.
* 💼 **Hands-on Experience:** Cleaning real-world data, writing investigative SQL queries to catch data anomalies, and cutting down manual reporting time.
* 🌱 **Continuously Learning:** Cloud data workflows on Azure, data pipeline fundamentals, and better ETL practices.
* 💬 **Ask me about:** SQL query logic, DAX measures, data cleaning in Python/Excel, or dashboard usability.
* ⚡ **Fun Fact:** I treat dashboard design like UI design—clean spacing, clear visual hierarchy, and colors that don't hurt the eyes matter just as much as the metrics!
